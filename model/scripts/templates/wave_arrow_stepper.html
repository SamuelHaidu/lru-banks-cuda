Loss per word

Cross entropy of each word given everything before it (state reset at the marker): green = the model expected it, red = it did not. Hover for the probability and the model's guess; click a word to step to the position that had to predict it and see why below.

Prediction and layer contributions

The logits are the sum over layers of (MLP output of the layer) x readout, so each layer's number is exactly what it adds to that token's logit. Green adds, red subtracts; the "all layers" row shows probabilities.

Channel clocks

One clock per channel, two rows per state space, ordered fast to slow (learned frequency, left to right, then the second row). Hand = state S after this token: angle = phase, length = amplitude relative to that channel's own peak in this text (full hand = the channel at its loudest; absolute values in the amplitude timeline below). Click a clock.

What the state holds now

Each token's share of the state after the current token: its write, decayed and turned since, projected on S, Re(conj(S) cj) / |S|2 (shares sum to 100%). Purple = adds to the state, red = cancels part of it (out of phase). Hover a token for its share, click it to jump there. Grey: not read yet, or before the last reset.
