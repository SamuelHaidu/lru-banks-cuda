Context heard (after the reader's filter)

The reader listens in stages, from the shortest range to the longest. Its query starts as its own signature, sets the filter of state space 1, and what state space 1 hears updates the query (a residual MLP on [query ; reading]), which sets the filter of state space 2, and so on. Per stage: what the query resembles (the closest token signatures), the filter it built (gain per channel), who the stage hears through that filter, and what the stage contributes to the prediction. A query whose closest signatures only reach cosine ~0.3 is no longer close to any single token: it has become a mix (read the filter and who the stage hears instead).
