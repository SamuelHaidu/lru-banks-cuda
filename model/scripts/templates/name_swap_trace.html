Why this report

Word order matters enormously to this model (see order-sensitivity-loss), but that alone doesn't say whether the model is content-sensitive copying (finding the specific earlier name and routing its identity forward) or template-level structural inference (using the sequence's shape -- "a name occupies this slot, in this narrative pattern" -- largely indifferent to which specific name is there). Each template's earlier name is swapped for every name in a {{ num_names }}-name pool, holding position, length, and every other token fixed. If the top prediction tracks the swap, that is copying; if it stays fixed regardless of which name was substituted, that is structural inference.
