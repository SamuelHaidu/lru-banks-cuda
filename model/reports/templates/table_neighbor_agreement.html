Why this report

The PGA report tests whether a single global rotation of an {{ dim_in }}-D summary of the big table matches the small table; the k-means report tests whether independent clusterings of each table agree. Both can understate a real relationship if it isn't a rigid rotation or a clean partition. This report asks the question directly, token by token: are a token's neighbors in the small table also its neighbors in the big table, and does small-table similarity predict big-table similarity at all?
