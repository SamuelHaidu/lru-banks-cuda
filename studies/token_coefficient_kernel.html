Token prior, per-token forgetting and repetition saturation

Predicting the token after the last word; distance k = 1 is the last word. Every vocabulary token has three learned numbers: a prior s, a forgetting rate λ, and a saturation κ for repeated mentions. Equal words share their numbers.
h = Σj st · δt(nj) · f(k; λt) · Rk et    (t = token at position j, k = its distance, nj = which mention of t it is: 1st, 2nd, ...)
forgetting (shared kernel w = env · osc, ŵ = env(k)/env(1)): log-mix f = env(1) ŵ(k)λ osc(k)  |  linear mix f = env(1) [(1-λ) + λ ŵ(k)] osc(k)
  λ = 1: forgets like the shared kernel; λ = 0: constant presence. Never stronger in the past than when it appeared.
saturation (order-based, "option B"): the n-th mention gets δ(n) = g(n) - g(n-1), so n mentions add up to g(n), bounded
  BM25: g(n) = n (1 + κ) / (n + κ)  → g(1) = 1, g(∞) = 1 + κ   |   power: g(n) = nα  (α = 1 additive, α = 0 only the first mention counts)
optional: divide by the total weight (weighted average)

Reading it
- Prior s alone is a rescaled embedding (a linear model can absorb it); it matters with normalization or when the embedding is reused elsewhere.
- Forgetting λ depends on distance, so it is new expressivity: with a power law and log-mix each token gets its own exponent k-λp, between "constant" and the shared decay.
- Saturation κ bounds repetition: with BM25, a token's mentions can never add up to more than s(1+κ) times one mention, however often it appears. Small κ: one mention is enough (names). Large κ: nearly additive (topic words).
- Saturation here is order-based: the 1st mention keeps full weight and later mentions get less, even if the 1st is old. That is what makes it cheap (one number per position, like s), parallel and recurrent; the exact version (saturate on the decayed weights per query) costs an extra (T × S) · (S × S) matmul.
- Everything here is a weight per (context position, distance), independent of the query, so the whole thing is a parallel banded sum; the linear mix even splits into a cumulative sum plus the shared-kernel convolution.
